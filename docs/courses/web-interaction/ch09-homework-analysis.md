## 二、命题规律

1. **三份作业严格对应三份课件**：作业一 = HTML5.pdf，作业二 = 4_CSS3基础.pptx，作业三 = JavaScript对象.pptx + JavaScript_DOM.pptx。作业三里有数组、DOM、BOM，唯独没有流程控制和函数，说明第五章的语法细节不是本课重点。
2. **同一个考点换皮重复**。作业二第 5、6、13 题全是 `margin` 简写，只是值的个数不同；作业三第 2、14 题是同一段 `new Array(3) + push` 代码。所以把本节例题吃透，等于把同类题全吃了。
3. **爱考「边界与顺序」**：`margin` 四个值的顺时针、超链接伪类的 LoVe HAte、`new Array(n)` 与 `new Array("a","b")` 的区别、`sort()` 默认按字符编码、CSS 引入方式的优先级——全是「看起来一样、其实不一样」的地方。
4. **判断题全是课本原句的改写**，一半是把对的改成错的（"必须提前编译"、"下标从 1 开始"、"能单独设置边框"）。判断时先找这句话里有没有绝对化词语。
5. **填空题考的是名词，不是理解**。三份作业 37 道填空，答案全是术语。

## 三、考点地图

### 3.1 HTML5（作业一，50 题）

| 考点 | 具体考什么 | 出现形式 |

| 列表与文本 | `ul/ol/dl` 三者区别、`p` `br` `hr`、`strong`/`b`、`h1`–`h6` | 判断 |

### 3.2 CSS3（作业二，28 题）

| 考点 | 具体考什么 | 出现形式 |
| --- | --- | --- |
| 作用与边界 | CSS 只管**表现**（修饰 + 布局），结构语义归 HTML，交互逻辑归 JS | 单选 |
| 三种引入 | 行内 `style=""`、内部 `<style>` 放 `head`、外部 `link rel="stylesheet"`；第四种 `@import url()` | 单选 + 填空 |
| 优先级 | 权重相同时**就近原则**：行内 > 内部 > 外部 | 单选 |

| `margin` 简写 | 1 值全同；2 值上下/左右；3 值上/左右/下；4 值上右下左（顺时针） | 单选 ×3 + 判断 |
| 边框分方向 | `border-top/right/bottom/left` 可单独设置 | 判断 |
| 块级水平居中 | **固定宽度** + `margin: 0 auto` | 单选 + 简答 |
| CSS3 趋势 | 模块化，新增圆角、阴影、动画、多背景；低版本浏览器**不**完美支持 | 填空 + 判断 |

### 3.3 JavaScript（作业三，40 题）

| 考点 | 具体考什么 | 出现形式 |
| --- | --- | --- |
| 三部分组成 | ECMAScript（核心语法）+ DOM + BOM，**没有 JVM** | 单选 + 判断 |
| 语言性质 | 解释型、跨平台、基于对象、事件驱动、与 HTML 结合紧密 | 单选 + 判断 |

## 四、常见失分点与答题规范

客观题丢分**几乎全在填空题上**，而且多数不是不会，是写法没对上。这几条比多背一个定义更值钱：

> 填空题按「术语 + 括号补英文」写全，比如 `内容（content）`、`类（class）`、`内边距（padding）`。只写中文常被判错。

- 「实现网页 __ 与样式的分离」只写 `内容` 判错，标准写法是 `内容（结构）`。
- 「标签选择器、__ 选择器、ID 选择器」只写 `类` 判错，标准写法是 `类（class）`。
- 「盒子模型内容、__、边框、外边距」只写 `内边距` 判错，标准写法是 `内边距（padding）`。

概念上最容易混的两处：

- 「每个文档的根节点是 __ 节点」要填 **文档**。`documentElement` 指的是 `<html>` 元素，也就是「文档元素」，比根节点低一层。
- 一个题干里两个空连着写（如 `window；document`、`length；concat()`）时，系统按「(1)」「(2)」分空判分，一个空只填一个词，写多了会把整题算错；两个空都有得分点，漏填一个就拿不到那部分分。

## 五、高频易错 10 条

1. `margin: 10px 20px 30px` 是「上 10、左右 20、下 30」，**不是**「上 10、下 20、左右 30」。三值时中间那个管左右。
2. `margin: 0 auto` 能居中，前提是元素**有固定宽度**且是块级；`text-align: center` 只管行内内容。
3. `new Array(3)` 得到一个长度 3 的空数组，不是 `[3]`。
4. `sort()` 不给比较函数时按**字符编码**排，`[10, 9, 1]` 会排成 `[1, 10, 9]`。
5. `push()` 返回新长度，`pop()` 返回被删的元素，`concat()` 不改变原数组。
6. DOM 的根节点是**文档节点**，`document.documentElement` 才是 `<html>`。
7. `window` 是 BOM 顶层，也是全局对象；`document` 是它的子对象，不是顶层。
8. 给 `window.location` 赋值就是跳转，`window.location.href` 赋值同理。
9. HTML 是标记语言，`<p>` 之间是 margin 撑开的间距，不是"空两行"的硬回车。
10. 表单里 `checked` 管单选/复选框预选，`selected` 管下拉项预选；`multiple` 管 `<select>` 多选——三个别混。

## 六、三小时复习路线

1. **40 分钟**：过一遍[例题精讲](./ch10-examples.md)，每类只看题干 + 答案，边看边在纸上写答案，写完对着核。
2. **40 分钟**：把第五节 10 条易错点抄到一张纸上，逐条能说出为什么。
3. **40 分钟**：手写 `margin` 四种简写、`new Array` 两种创建方式、`sort/pop/join/concat` 各一句结论。
4. **30 分钟**：背三道简答的要点（盒子模型四层 + margin 规则 + 居中条件、标准 HTML5 文档结构、标记/脚本/编程语言三者的区别）。
5. **30 分钟**：只看[考前速查表](./cheat-sheet.md)，把表格当小抄。
