# 第 1 章 Web 前端开发概述

> 本章是概念的集中区，考点全在名词解释和流程描述上，几乎不写代码。记住一条主线：**Web 是建立在 Internet 上用超文本和 HTTP 提供信息的服务系统 → 它分前端和后端 → 前端又分结构、样式、行为三层**。

---

## 一、Web 是什么

教材式定义（建议背关键词）：

> Web（World Wide Web，万维网）是一种基于**超文本**和 **HTTP** 的、全球性的、动态交互的、跨平台的**分布式图形信息系统**；是建立在 Internet 上，通过图形化的、易于访问的直观界面为浏览者提供信息的网络服务。

拆开看四个定语：基于超文本和 HTTP、全球性、动态交互、跨平台。考试问“Web 的定义”，把这几句写全即可。

### 1.1 Web 的三种表现形态

| 名词 | 含义 |
| --- | --- |
| 超文本 HyperText | 按**关键字建立链接**的全局性信息结构，信息可以按交互方式检索 |
| 超媒体 UltraMedia | 用非线性网状结构组织**块状多媒体信息**（文本、图像、视频等），是超文本 + 多媒体的结合 |
| HTTP | 超文本在互联网上的**传输协议** |

一句话区分：超文本讲“链接”，超媒体讲“链接 + 多种媒体”，HTTP 讲“怎么传”。

### 1.2 Web 的起源（时间线爱考填空）

| 时间 | 事件 |
| --- | --- |
| 1980 年 | Tim Berners-Lee 负责 Enquire（Enquire Within Upon Everything）项目，是 Web 的前身 |
| 1989 年 | Tim Berners-Lee 提出 Web 的应用架构 |
| 1990 年 11 月 | 第一个 Web 服务器 `info.cern.ch` 开始运行，第一个图形化浏览器出现 |
| 1991 年 | CERN（欧洲粒子物理研究所）正式发布 Web 技术标准 |
| 1994 年 | W3C 成立，负责维护 Web 相关技术标准 |

## 二、前端与后端

- **前端**：网页上为用户呈现的部分，负责界面与交互。
- **后端**：与数据库交互，完成数据存取和业务逻辑。

判断口诀：看得见的是前端，算数据、连数据库的是后端。

## 三、Web 基本概念：网站、网页、主页

| 概念 | 定义 |
| --- | --- |
| 网站 web site | 互联网上用于展示特定内容的**相关网页的集合** |
| 网页 web page | 网站中的一页，通过**超链接**组织在一起；由文字、声音、动画等多种媒体组成 |
| 主页 homepage | 进入网站看到的第一个网页，文件名通常是 `index` |

网页中的媒体元素：文本、图像、音频、视频。常见页面元素：Logo（站标）、导航栏、banner 广告横幅、表单、文字超链接。

## 四、网页的浏览过程（四步，简答高频）

1. **启动浏览器**：在地址栏输入 URL，通过 HTTP 协议向该 URL 所在的服务器发起请求。
2. **服务器处理请求**：把 URL 转换成服务器上的实际路径，找到对应的网页文件。
3. **反馈网页**：如果页面只有 HTML 标记，服务器直接通过 HTTP 把文档发给客户端；如果含 JSP 等动态程序，则先在服务器执行，再把运行结果发给客户端。
4. **客户端显示网页**：浏览器解释 HTML 文档，把结果显示在客户端。

## 五、前端三大技术：结构、样式、行为

| 技术 | 全称 | 作用 | 层级 |
| --- | --- | --- | --- |
| HTML | Hypertext Markup Language，超文本标记语言 | 从**语义**的角度描述页面结构 | 结构 |
| CSS | Cascading Style Sheet，层叠样式表 | 从**审美**的角度美化页面，实现内容与格式分离 | 样式 |
| JavaScript | 解释型、基于对象的脚本语言 | 从**交互**的角度提升用户体验 | 行为 |
| jQuery | JavaScript 库 | 封装 DOM 操作、事件、动画、Ajax，简化开发 | 行为 |

> 考点：HTML **不是**编程语言，是标记语言；JavaScript 是脚本语言，不是 Java。

## 七、Web 前端开发流程（五阶段）

1. **需求分析**：确立建站目标、面向用户、要实现的功能。
2. **设计阶段**：明确栏目组成、页面内容、链接结构，输出页面详细设计文档。
3. **制作阶段**：前台页面制作 → 页面代码书写（CSS/JS 美化与交互）→ 后台程序开发（数据库与数据表）。
4. **测试**：功能性测试、性能测试（连接速度、负载、压力）、可用性测试（主观/客观）、安全性测试。
5. **维护和更新**：增加新内容与功能，定期维护。

建站目的通常有四类：产品服务销售、公益性服务、宣传思想观念、让业务走向世界。网站特色要在「内容为本 / 视觉设计 / 大量图和动画 / 打开速度」之间取舍。

## 八、开发工具与从业要求

常见工具：EditPlus（小巧的 Windows 编辑器）、Dreamweaver（所见即所得）、Sublime Text、HBuilder X（主打快）。

前端工程师职责：配合前端设计师完成界面美化，配合后端程序员实现用户交互设计。核心技术栈：HTML5、CSS、JavaScript、jQuery、Ajax；还需了解响应式布局、Bootstrap、AngularJS 等框架。

## 九、W3C 与标准

W3C（World Wide Web Consortium，万维网联盟）成立于 1994 年，是 Web 领域最权威、最具影响力的国际中立性技术标准机构（`www.w3.org`）。

W3C 标准包括三部分：

- 结构化标准语言：XHTML、XML
- 表现标准语言：CSS
- 行为标准：DOM、ECMAScript

W3C 提倡**内容与结构分离**、HTML 结构**语义化**。

## 十、本章小结（教材原话，直接背）

- Web 开发技术可分为**客户端技术**和**服务器端技术**两大类。
- Web 客户端主要任务是展现信息内容，技术包括 HTML、CSS、JavaScript 等。
- Web 服务器技术主要包括 PHP、ASP、ASP.NET、JSP 等。
- 常用前端框架：Bootstrap、Angular、React、Vue。
