# 第 4 章 CSS3 布局

> 这章是考试里“算尺寸 + 手写布局”的主战场。三条主线：**盒子模型算总宽**、**浮动与清除**、**四种定位的基准与是否脱离文档流**。把手写题当真练两遍，基本不会错。

---

## 一、盒子模型 Box Model

每个元素都是一个盒子，由内到外四层：

| 层 | 属性 | 说明 |
| --- | --- | --- |
| 内容 content | `width` / `height` | 盒子的主要信息 |
| 内边距 padding | `padding-*` | 内容与边框的距离，也称“填充” |
| 边框 border | `border-*` | 盒子外壳的厚度 |
| 外边距 margin | `margin-*` | 与其他盒子的距离，也称“边界” |

> 最容易错的知识点：`padding` 是内容与边框的距离，`margin` 是盒子与盒子之间的距离。课件小结那一页把两者写反了，以盒子模型图和手写题为准。

### 1.1 外边距 margin

`margin-top` / `margin-right` / `margin-bottom` / `margin-left` 与简写 `margin`。

简写按**顺时针：上 右 下 左**。

```css
margin: 3px 5px 7px 4px;  /* 上3 右5 下7 左4 */
margin: 3px 5px 7px;      /* 上3 左右5 下7 */
margin: 3px 5px;          /* 上下3 左右5 */
margin: 8px;              /* 四边均 8 */
```

网页常用的水平居中技巧：

```css
.box { width: 300px; margin: 0 auto; }
```

必要条件两个：**块级元素** + **固定宽度**。如果写 `height: 3%` 这类百分比，高度是相对父元素算的，容易“看不见”。

### 1.2 边框 border

| 属性 | 取值 |
| --- | --- |
| `border` | 简写，如 `border: 1px solid red;` |
| `border-width` | thin / medium / thick / 像素值 |
| `border-style` | none / hidden / dotted / dashed / solid / double / groove / ridge / inset / outset |
| `border-color` | 颜色值，可 1～4 个值（按上右下左） |
| `border-top` 等 | 单独设置某一边 |

`border-color` 的 1/2/3/4 值写法与 margin 同理：一值四边相同；两值上下、左右；三值上、左右、下；四值上右下左。

### 1.3 内边距 padding

`padding-top` / `right` / `bottom` / `left` / `padding`，简写规则与 margin 完全一致。

### 1.4 盒子总尺寸（必考计算）

默认 `box-sizing: content-box` 时：

```
盒子实际宽度 = width + padding-left + padding-right + border-left + border-right
盒子总占位 = 实际宽度 + margin-left + margin-right（水平方向）
```

例：`width:70px; padding:5px; border:2px solid; margin:10px;`

- 实际宽度 = 70 + 5×2 + 2×2 = 84px
- 水平总占位 = 84 + 10×2 = 104px

若设 `box-sizing: border-box`，`width` 就包含 padding 与 border，写多少就是多少，布局时更省心。

### 1.5 圆角与阴影

```css
/* 四值顺时针：左上 右上 右下 左下 */
border-radius: 20px 10px 50px 30px;

/* 圆形：宽高相等 + 半径 50% */
.circle { width: 100px; height: 100px; border-radius: 50%; }

/* 盒子阴影：水平偏移 垂直偏移 模糊半径 颜色 */
box-shadow: 4px 4px 10px #ccc;
```

用 `border-radius` 做特殊图形的要点：

| 图形 | 要点 |
| --- | --- |
| 圆形 | 宽高相同，圆角半径为宽高一半（或 50%） |
| 半圆 | 上下半圆：宽是高的 2 倍，半径为高度值；左右半圆：高是宽的 2 倍，半径为宽度值 |
| 扇形 | “三同，一不同”：宽、高、圆角半径相同，只是圆角取值位置不同 |
| 饼环 | 四边不同颜色 + 大圆角 |

## 二、DIV + CSS3 布局

布局思路两步：

1. 先把页面分成版块，用 HTML5 语义标签描述结构。
2. 再用 CSS3 描述各版块的**位置、尺寸、边距**；位置一般由浏览器自动控制。

```css
/* 布局前先清除默认边距 */
* { margin: 0; padding: 0; }
```

常见版式：

```
1-2-1：导航 / 左侧链接 + 右侧内容 / 版权
1-3-1：导航 / 左中右三栏 / 版权
```

典型的整体布局要求：广告区、导航区、主体区（左文章列表 + 右侧内容区）、版权信息区。

## 三、标准文档流

> 标准文档流：元素按块元素或行内元素的特性，从上到下、从左到右自然排列。这就是元素的默认排列方式。

| 类型 | 默认排列 | 常见标签 |
| --- | --- | --- |
| 块级元素 block | 独占一行，可设宽高 | `h1`–`h6`、`p`、`div`、`ul`/`ol`/`li`、`table`、`form` |
| 内联元素 inline | 内容撑开宽度，可并排 | `span`、`a`、`img`、`strong`、`em` |

内联可以包含在块级里，反过来不行。

## 四、display 属性

| 值 | 说明 | 用途 |
| --- | --- | --- |
| `block` | 块级元素默认值，前后带换行 | 把行内元素变块 |
| `inline` | 内联元素默认值，前后无换行 | 把块元素变行内 |
| `inline-block` | 行内块，既有内联的并排，又能设宽高 | 让块元素排在一行 |
| `none` | 不显示、不占位 | 显示 / 隐藏切换 |

`display:none` 与 `visibility:hidden` 的区别：前者**不占位置**，后者**占位置但看不见**。

## 五、浮动 float 与清除

```css
.a { float: left; }
.b { float: right; }
```

`float` 取值：`left` / `right` / `none`（默认，不浮动，显示在文本出现的位置）。

浮动的三大特征（必背）：

1. 块级元素失去块状换行特性，变成类似行内元素（可以并排）。
2. 紧贴同方向的浮动元素或父级边框；**宽度不够就换行**。
3. 占据行内标签的空间，导致行内文字围绕它显示。

清除浮动 `clear`：`left` / `right` / `both` / `none`，**只对块级元素有效**。

```css
.footer { clear: both; }
```

清除浮动的常用写法：在浮动元素之后加一个带 `clear: both` 的块（或给父级加 `overflow: hidden` 形成 BFC）。

### inline-block 与 float 的对比（简答常考）

| 对比项 | `display:inline-block` | `float` |
| --- | --- | --- |
| 能否排一行 | 能，且支持宽高，代码简单 | 能，且支持宽高 |
| 方向控制 | 不可控，还会解析代码中的空格 | 可控（left/right） |
| 对周围影响 | 不脱离文档流 | 脱离文档流，影响周围元素，必须清除浮动 |
| 兼容性 | IE6/IE7 不支持 | 兼容较好 |

## 六、溢出处理 overflow

| 值 | 效果 |
| --- | --- |
| `visible` | 默认，不修剪，溢出到盒子外 |
| `hidden` | 修剪，其余不可见 |
| `scroll` | 修剪，总是显示滚动条 |
| `auto` | 修剪，需要时才出现滚动条 |

## 七、定位 position

| 值 | 基准 | 是否脱离文档流 | 原位置 | 典型用途 |
| --- | --- | --- | --- | --- |
| `static` | 无定位，按标准流显示（默认） | 否 | — | 普通内容 |
| `relative` | 相对**自身原来位置**偏移 | 否 | 保留 | 给子元素做定位父级 |
| `absolute` | 相对**最近的已定位祖先**，无则相对浏览器窗口 | 是 | 不保留 | 轮播、下拉菜单、气泡、定位广告 |
| `fixed` | 相对**浏览器窗口** | 是 | 不保留 | 固定广告、返回顶部、吸顶导航 |

偏移属性：`top` / `right` / `bottom` / `left`。

```css
/* 常见组合：父相子绝 */
.box { position: relative; }
.box .tip { position: absolute; right: 0; bottom: 0; }
```

几个容易被考的“规律”：

- 相对定位仍占在标准流里，对父级和相邻盒子没有影响，原位置保留；层级提高，能盖住普通元素与浮动元素。
- 绝对定位脱离文档流，原位置不保留；若只设 `position:absolute` 而不设偏移量，元素会**停在原来的位置**（常用作“脱离文档流但不挪位置”的技巧）。
- 固定定位的偏移量**不随滚动条移动**。

> 一句话概括定位设计思路：相对定位当“爹”（做基准），绝对定位当“儿子”（跑位置），固定定位当“钉子”（钉在窗口上）。

## 八、浮动与定位的区别

- 浮动原本是解决**图片与文字排版**问题的，被大量用到布局里，成为公认的布局方式；需要清除浮动。
- 定位用于让元素出现在**指定位置**，绝对/固定定位直接脱离文档流，不需要清除浮动，但会覆盖其他内容。
