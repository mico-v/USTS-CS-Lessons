# 第 1 章 绪论

> 这一章不考代码，全靠选择题 + 名词解释拿分：**逻辑结构与存储结构的区分**、**四类逻辑结构**、**算法五个特性**、**时间复杂度计算**。最后一项是必考题，练到看程序段就能直接写阶为止。

## 一、先看这门课解决什么问题

课件第一页就摆出沃斯（Niklaus Wirth）的公式：

$$\text{算法} + \text{数据结构} = \text{程序}$$

- **数据结构**：问题的数学模型，反映数据以及数据之间的关系（逻辑结构 + 存储结构）。
- **算法**：处理问题的策略，是对数据运算的描述，是程序的逻辑抽象。
- **程序**：为计算机处理问题而编制的一组指令集。

求解一个问题的四个步骤（课件明确列出的顺序）：

1. 确定求解问题的数学模型（逻辑结构）；
2. 确定存储结构；
3. 设计算法；
4. 编程并测试结果。

课件有三个引例，考试常拿来问“这属于哪种逻辑结构”：

| 引例 | 模型 |
| --- | --- |
| 电话号码查询（按姓名查号码） | 线性结构 |
| 计算机对弈 / 各种淘汰赛制 | 树 |
| n 个城市间铺设光缆、总经费最省 | 图 |

## 二、数据结构研究的三个方面

1. **数据的逻辑结构**——数据元素之间的关系（抽象出来的“数据表示”）。
2. **数据的存储结构**（物理结构）——逻辑结构在存储器中的具体实现。
3. **数据的运算**——在数据结构上实现的功能，用算法描述，用程序实现。

课件给的那张“过程”表可以这么记：**抽象**得到逻辑结构 + 基本运算，**实现**落到存储结构 + 算法，最后**评价**是对不同数据结构和算法性能的比较分析。

这门课是操作系统、编译原理、人工智能的基础。

## 三、基本概念（名词必背）

| 术语 | 定义 | 记法 |
| --- | --- | --- |
| 数据 data | 信息的载体，是对客观事物的符号表示，能被计算机识别、存储和加工处理 | 图像、声音、视频编码后也算数据 |
| 数据元素 data element | 数据的基本单位，也称元素、结点、记录 | 可由若干数据项组成 |
| 数据项 | 数据不可分割的最小单位，也叫字段、域 | 学生记录里的“学号”“姓名” |
| 数据对象 data object | 数据的子集，具有相同性质的数据元素的集合 | 全体学生记录 |
| 数据结构 data structure | 数据元素 + 结构（元素之间的关系） | 见下面的二元组 |

数据——数据对象——数据元素——数据项，是**从大到小**的四层包含关系，选择题常把顺序打乱来问。

### 3.1 形式定义（课件 p4）

数据结构是一个二元组：

$$\text{Data\_Structures} = (D, R)$$

- $D$ 是数据元素的有限集 $\{D_i \mid 1 \le i \le n,\ n \ge 0\}$；
- $R$ 是 $D$ 上关系的有限集 $\{R_j \mid 1 \le j \le m,\ m \ge 0\}$。

关系用序偶表示：

- $\langle a_i, a_j \rangle$：**有向**关系，画成带箭头的弧，$a_i$ 是前驱（弧尾），$a_j$ 是后继（弧头）；
- $(a_i, a_j)$：**无向**关系，画成边。

课件的例 1-1（某公司 1 名经理、2 名部门经理、每部门 3 名职员）同一个集合 $D$，换一种关系 $R$ 就是不同的数据结构：

| 关系 | $R$ 的形态 | 逻辑结构 |
| --- | --- | --- |
| 经理指导部门经理、部门经理指导职员 | $\langle M, D_1\rangle, \langle D_1, E_{11}\rangle \dots$ | 树（一对多） |
| 按年龄从大到小排列 | $\langle D_1, M\rangle, \langle M, E_{11}\rangle \dots$ | 线性（一对一） |
| 人员之间的友好关系 | $(M, D_1), (D_1, D_2) \dots$ | 图（多对多） |

> 注意这里第一个人和最后一个人也串起来了（$\langle E_{22}, E_{23}\rangle$ 之类的写法），试卷上问“这是不是线性表”要看清是不是首尾都有前驱/后继。

### 3.2 四类逻辑结构

1. **集合**：元素之间只有“同属一个集合”的关系。
2. **线性结构**：一对一，除首尾外每个元素有且仅有一个前驱和一个后继。
3. **树型结构**：一对多，有且仅有一个根（无前驱），可有多个叶子（无后继）。
4. **图状结构**：多对多。

### 3.3 四类存储结构

| 存储结构 | 表示关系的方式 |
| --- | --- |
| 顺序存储 | 用元素间存储的**相对位置**表示关系（数组） |
| 链式存储 | 用存储元素的**指针**表示关系 |
| 索引存储 | 附加索引表，用索引项指示元素位置 |
| 散列存储 | 由关键字直接算出存储地址 |

> 本章只详细讲前两种，后两种在查找那一章（散列表）用得多。考试常问“顺序存储和链式存储的本质区别”——前者靠位置，后者靠指针。

### 3.4 数据类型与抽象数据类型

- **数据类型**：数据的取值范围 + 数据的结构 + 允许施加的运算。分简单类型（int、char）和构造类型（数组、结构体）。
- **抽象数据类型 ADT**：数据结构 + 数据结构上的操作。数据结构包括数据元素和元素间关系，操作指要在数据结构上实现的功能，通过算法转换成源程序来实现。

课件特别写了：**在 Java 语言中通过类的方法实现**。这也是全书代码风格——先是 `interface IList / IStack / IQueue` 定义操作集合，再用 `SqList / LinkList / SqStack / LinkStack / CircleSqQueue` 等类实现。

## 四、算法和算法分析

### 4.1 算法的定义与五个特性

算法是对特定问题求解步骤的描述，是指令的有限序列。**五个特性**（必背）：

1. **有穷性**：执行有限条指令后一定终止，且必须在有限时间内完成。
2. **确定性**：每条指令含义明确，无二义性。
3. **可行性**：指令是计算机能执行的。
4. **输入**：有零个或多个输入。
5. **输出**：有一个或多个输出。

> 与“程序”的区别是常考判断题：程序不一定满足有穷性（比如死循环的操作系统程序），算法的指令不要求机器可执行（用类程序设计语言写的也算算法），程序的一定可执行。

### 4.2 描述算法的方法

自然语言、程序设计语言、类程序设计语言（伪代码/类 C、类 Java）、流程图。本课程统一用**类 Java 语言**描述。

### 4.3 算法设计的目标与原则

- **有穷性**、**可执行性**（见上）。
- **正确性**，分四个层次（课件层层递进）：
  1. 不含语法错误；
  2. 对于几组输入数据能得出满足要求的结果；
  3. 对于精心选择的、典型的、苛刻的、带有刁难性的几组输入数据也能得出满足要求的结果；
  4. 对于一切合法的输入数据都能得出满足要求的结果。
- **健壮性**：输入非法时能适当做出反应、终止执行，而不是给出莫名其妙的结果或出错信息。
- **可读性**：方便阅读和交流。
- **高效性**：执行算法所耗费的**时间**和**空间**，是评价算法优劣的重要依据。

> 正确性的四层次是标准简答题：从“语法对”到“几组对”到“刁难数据对”到“一切合法输入都对”，一层比一层强。

### 4.4 时间复杂度的分析方法

两种方法：

- **事后统计法**：编好程序实际运行计时。缺点是要先有程序、受机器和语言影响。
- **事前估算法**（本课程用）：分析算法本身。影响算法时间的五个因素：算法采用的策略、问题的规模、书写程序的语言、编译产生的机器代码质量、机器执行指令的速度。

**语句频度** = 该语句重复执行的次数；语句执行时间 = 频度 × 一次执行时间；算法耗费时间 = 所有语句执行时间之和。

课件例题：求两个 $n$ 阶方阵的乘积 $C = A \times B$：

```java
for (i = 0; i < n; i++)              // n+1
    for (j = 0; j < n; j++) {        // n*(n+1)
        C[i][j] = 0;                 // n*n
        for (k = 0; k < n; k++)      // n*n*(n+1)
            C[i][j] += A[i][k] * B[k][j];   // n*n*n
    }
```

$$T(n) = (n+1) + n(n+1) + n^2 + n^2(n+1) + n^3 = 2n^3 + 3n^2 + 2n + 1$$

所以 $T(n) = O(n^3)$。**只要最高阶，系数和低阶全扔**。

### 4.5 渐近时间复杂度

随着问题规模 $n$ 的增长，算法执行时间的增长率和 $f(n)$ 的增长率相同，记作

$$T(n) = O(f(n))$$

估算方法（课件给的实操规则）：

- $f(n)$ 一般取算法中**频度最大的语句**，通常是**最深层循环内**的原操作执行次数；
- 循环次数未知（与输入数据有关）时，求**最坏情况**下原操作的重复次数。

常见阶的关系（从小到大）：

$$c < \log_2 n < n < n\log_2 n < n^2 < n^3 < 2^n < n! < n^n$$

其中指数级之间还有 $O(2^n) < O(n!) < O(n^n)$ 的写法。

课件的五个小段（几乎就是考试原题）：

```java
// (1)
x = 0; y = 0;                    // O(1) 常数阶
// (2)
temp = x; x = y; y = temp;       // O(1) 常数阶
// (3)
for (i = 1; i <= n; i++) x++;    // O(n) 线性阶
// (4)
for (j = 1; j <= n; j++)
    for (k = 1; k <= n; k++) x++;   // O(n^2) 平方阶
// (5)
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j++)
        for (k = 1; k <= n; k++) x++;   // O(n^3) 立方阶
```

### 4.6 最好、最坏、平均情况

算法的时间不仅是 $n$ 的函数，还与所处理的数据集有关。课件给的例子最直观：对 10 个数做查找，

- 数据集 `1,2,3,…,10`：一次就命中 → 最好情况；
- 数据集 `10,9,8,…,1`：要找的若是 1，得比 10 次 → 最坏情况。

全面分析算法应同时给出**最坏**、**最好**、**平均**三种代价。课程默认讨论**最坏时间复杂度**（除非题目明说平均）。

### 4.7 空间复杂度

$$S(n) = O(g(n))$$

算法所需的存储量由三部分组成：

1. 输入数据所占空间；
2. 程序本身所占空间；
3. **辅助变量所占空间**（这才是通常讨论的对象）。

课件例题：冒泡排序每轮找最小记录并交换，只需要 1 个中间变量 `temp`，与 $n$ 无关，所以空间复杂度 $O(1)$。

> 只要算法额外占用的空间是常数个变量，就是 $O(1)$；递归算法的空间复杂度 = 递归深度（每层要存局部变量和返回地址）。

## 五、易错点清单

1. 把“数据元素”和“数据项”搞反：数据元素是**基本单位**，数据项是**最小单位**。
2. 逻辑结构和存储结构混谈：逻辑结构只有四类（集合/线性/树/图），存储结构是顺序/链式/索引/散列，**同一个逻辑结构可以有不同存储结构**。
3. $O(1)$ 不等于“执行一次”，只要执行次数与 $n$ 无关就是 $O(1)$。
4. 复杂度写 $O(2n^2+3n)$ 是错的，必须写成 $O(n^2)$；$\log_2 n$ 和 $\ln n$ 同阶，写成 $O(\log n)$ 即可。
5. 有穷性是“算法”的必要条件，但对“程序”不是。
6. 双重循环不一定是 $O(n^2)$，看内层循环次数是否真的与 $n$ 相关（如 `for(i=1;i<=n;i*=2)` 是 $O(\log n)$）。

## 七、三分钟自测

1. 数据结构的形式定义是什么？二元组里 $D$ 和 $R$ 各表示什么？

4. 正确性的四个层次怎么排序？
5. 求下面程序段的时间复杂度：

```java
int i = 1;
while (i <= n) {
    i = i * 2;
    x++;
}
```

> 答案：$O(\log n)$，因为 $i$ 每次翻倍，循环执行 $\lfloor \log_2 n \rfloor + 1$ 次。
