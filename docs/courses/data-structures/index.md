## 复习路线

只剩一天：

1. 先看[速查表](./cheat-sheet.md)的公式部分，把四类公式背下来（复杂度、循环队列、二叉树性质、数组下标）。
2. 再看第 2、3 章的代码模板，顺序表/链表/栈/队列各默写一遍。
3. 最后练第 5 章的三类计算题：给结点数求叶子数、给两种序列还原二叉树、给权值画哈夫曼树。

有两天：

1. 第 1、4 章是“纯计算 + 名词”，两小时能过完，性价比最高。
2. 第 2、3 章练手写算法（答题三段式：算法步骤 → 代码 → 复杂度）。
3. 第 5 章占分最多，先性质后遍历最后哈夫曼，课件里的附加题 5 道就是最好的练习。

## 这本书的题型分布（按课件重点推断）

- **选择题/填空**：逻辑结构四类、存储结构四类、算法五特性、$n_0=n_2+1$、循环队列条件、空串与空白串、复杂度判阶。
- **计算题**：顺序表平均移动次数、矩阵下标换算、$m \times n$ 数组地址、二叉树叶结点数、完全二叉树深度。
- **画图题**：链表指针图、顺序存储/二叉链表表示、哈夫曼树、森林转二叉树。
- **算法设计题**：顺序表/链表插入删除、循环队列入队出队、二叉树遍历与应用（查找/计数/深度）、建树。
- **简答**：顺序表与链表的比较、栈与队列的异同、二叉树的五条性质（含证明）、哈夫曼编码为什么是前缀码。
