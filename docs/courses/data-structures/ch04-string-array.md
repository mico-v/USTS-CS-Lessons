# 第 4 章 串和数组

> 这章分数集中在**计算**上：数组地址公式、对称/三角/对角矩阵的下标换算、稀疏矩阵转置的复杂度。串的定义和 BF 算法偏概念题，会写“下标怎么算”的能手算题几乎必出一道。

---

## 第一节 串

### 1.1 定义与三个易混概念

串（string）是由**零个或多个字符**组成的有限序列，记作 $s = \text{"}a_1a_2\dots a_n\text{"}$。两边的双引号不算串值，$n$ 为串的长度。

| 概念 | 含义 | 例子 |
| --- | --- | --- |
| 空串 | 不含任何字符，长度 $n = 0$ | `""` |
| 空白串 | 含一个空格，长度 $n = 1$ | `" "` |
| 子串 | 一个串中**连续的一段** | `"abcdefg"` 是 `"fabcdefghxyz"` 的子串 |
| 主串 | 相对于子串而言的那个串 | 上例中后者是主串 |

两条性质：**空串是任意串的子串；任意串是自身的子串。**

> 易错：`""`（空串）和 `" "`（空白串）长度不同；“子串”必须是连续的字符段，“ade” 这种跳字符的不算，那叫子序列。

### 1.2 串的九种运算（课件全列了）

约定：大写字母表示串名，小写字母表示组成串的字符。

| 运算 | 形式 | 含义 |
| --- | --- | --- |
| 赋值 | `assign(S, T)` | 把 T 的值赋给 S |
| 联接 | `concat(S, T)` | 把 T 接到 S 后面 |
| 求长度 | `length(T)` | 求 T 的长度 |
| 求子串 | `substr(S, i, j, T)` | 从 S 第 i 个字符起取连续 j 个字符存入 T |
| 比较 | `strcmp(S, T)` | S<T 返回负，相等返回 0，S>T 返回正 |
| 插入 | `insert(S, i, T)` | 在 S 的第 i 个位置插入 T |
| 删除 | `delete(S, i, j)` | 删除 S 中从第 i 个字符起连续 j 个字符 |
| 定位 | `index(S, T)` | T 在 S 中首次出现的位置，不是子串则返回 0 |
| 替换 | `replace(S, i, j, T)` | 用 T 替换 S 中从 i 起连续 j 个字符 |

### 1.3 串的存储结构

**（1）顺序存储（顺序串）**：用字符数组存。

**（2）链式存储**：两种结点大小。

- **结点大小为 1**：每个结点一个字符，和单链表一样，也可以带头结点；
- **结点大小为 K**：一个结点有 K 个数据域 + 1 个指针域，不满的用 `ø` 补齐。$K=4$ 时的结点定义：

```c
struct link4 {
    char data[5];          // 只用 data[1] ~ data[4]
    struct link4 *next;
};
```

> 结点大小越大，存储密度越高，但插入、删除时移动字符的代价越大。

**（3）索引存储**：用串名作关键字组织索引表（名字表），表项存串名和串值位置的对应关系。

### 1.4 模式匹配（BF 算法）

朴素（Brute-Force）匹配：主串 `s` 从 `pos` 位开始，与模式 `t` 逐字符比较，失配则主串起点后移一位重来。

```c
int bf(char s[], char t[], int pos) {
    int k, i, j;
    i = pos; j = 0; k = i;             // k 记录本轮起点
    while (s[i] != '\0' && t[j] != '\0') {
        if (s[i] == t[j]) { j++; i++; }
        else { k++; j = 0; i = k; }    // 失配：起点后移，j 归零
    }
    if (t[j] == '\0') return k;        // 匹配成功，返回起点
    else return -1;
}
```

课件紧接着给了一个简化版（用 `s[i+j]` 省掉 `k`）：

```c
int index_bf(char s[], char t[], int pos) {
    int i, j;
    i = pos; j = 0;
    while (s[i + j] != '\0' && t[j] != '\0') {
        if (s[i + j] == t[j]) j++;
        else { i++; j = 0; }
    }
    if (t[j] == '\0') return i;
    else return -1;
}
```

复杂度：设主串长 $n$、模式长 $m$，最好情况 $O(m)$，最坏情况 $O(n \times m)$（每趟都比较到模式末尾才失配），平均 $O(n+m)$ 量级。

> 教材后续会讲 KMP，把最坏情况降到 $O(n+m)$。本课程课件只到 BF，考试如果只问“朴素匹配的最坏复杂度”，答 $O(n \times m)$。

## 第二节 数组

### 2.1 定义与特点

数组可以看成一种特殊的线性表：线性表中的数据元素本身也是一个线性表。

三个特点：

1. **结构固定**——维数和各维长度一旦确定就不再改变；
2. **数据元素同构**——所有元素类型相同；
3. 运算只有两种：给定一组下标**存取**元素、给定一组下标**修改**元素的值。

> 正因为“结构固定 + 元素同构”，数组才能用顺序存储并且能直接算出地址，这就是“随机存取”的由来。数组一般不做插入删除。

### 2.2 顺序存储与地址计算（必考）

两种次序约定：**以行序为主序**（行优先，C/Java/Pascal）和**以列序为主序**（列优先，Fortran）。

设二维数组 $a[m][n]$，每个元素占 $l$ 个存储单元，$a_{11}$ 的地址为 $\text{Loc}(a_{11})$：

**按行序为主序**：

$$\text{Loc}(a_{ij}) = \text{Loc}(a_{11}) + [(i-1)\,n + (j-1)] \times l$$

**按列序为主序**：

$$\text{Loc}(a_{ij}) = \text{Loc}(a_{11}) + [(j-1)\,m + (i-1)] \times l$$

> 如果数组下标从 0 开始（本课程后半段的代码都是 0 起），公式改成 $\text{Loc}(a_{ij}) = \text{Loc}(a_{00}) + (i \times n + j)\times l$。**先看题目给的下标起点，再套公式**，这是最常见的失分点。

## 第三节 矩阵的压缩存储

压缩存储的原则：**值相同的元素只分配一个存储空间；零元素不分配空间**。

### 3.1 对称矩阵

$n$ 阶对称矩阵满足 $a_{ij} = a_{ji}$，只需存下三角（含对角线）共 $\dfrac{n(n+1)}{2}$ 个元素，按行序为主序：

$$k = \frac{i(i+1)}{2} + j \quad (i \ge j)$$

若 $i < j$（上三角部分），利用对称性取 $a_{ji}$，即把公式里 $i$、$j$ 对调。

下标范围：$0 \le k \le \dfrac{n(n+1)}{2} - 1$。

例：$n=4$，$a_{21}$ → $k = \frac{2\times3}{2} + 1 = 4$。（行内序号：第 0 行 1 个、第 1 行 2 个、第 2 行 3 个，$a_{21}$ 是第 2 行第 2 个 → 1+2+1 = 4，对得上。）

### 3.2 三角矩阵

上三角全为常数 $c$ 的下三角矩阵（或反之），只存非常数部分 + 一个常数 $c$：

$$k = \begin{cases} \dfrac{i(i+1)}{2} + j & i \ge j \\[4pt] \dfrac{n(n+1)}{2} & i < j \end{cases}$$

常数 $c$ 存在最后一个位置，总空间 $\dfrac{n(n+1)}{2} + 1$。

### 3.3 对角矩阵（带状矩阵）

三对角矩阵只有主对角线及其上下各一条对角线非零，共 $3n - 2$ 个非零元。按行序存：

$$k = \begin{cases} 3i - 1 & i > j \\ 3i & i = j \\ 3i + 1 & i < j \end{cases}$$

（本课程约定下标从 0 开始，$0 \le k \le 3n-3$。）

验证：$a_{00} \to k=0$；$a_{01} \to 1$；$a_{10} \to 3\times1-1=2$；$a_{11} \to 3$；$a_{12} \to 4$…… 每行最多 3 个，紧凑无空隙。

### 3.4 稀疏矩阵

定义：非零元较少且分布没有一定规律的矩阵。压缩原则：只存行列维数 + 每个非零元的行列下标和值。

例：$M$ 由 `{(0,1,12), (0,2,9), (2,0,-3), (2,5,14), (3,2,24), (4,1,18), (5,0,15), (5,3,-7)}` 和维数 $(6,7)$ 唯一确定。

**（1）三元组表（顺序存储）**

```c
struct node {
    int i, j;
    elemtype v;
};
struct matric {
    int rows, cols;
    int nozeros;
    struct node a[N];
};
```

**（2）伪地址表示法**

伪地址 = 该元素在矩阵中（包括零元素在内）按行优先顺序的相对位置。用 (伪地址, 值) 两个域存。例：`(0,1,12)` 的伪地址是 $0\times7+1 = 1$，`(5,3,-7)` 是 $5\times7+3 = 38$。优点是省一个下标域，缺点是求行列号要反算。

**（3）转置（必考）**

一般矩阵转置是双重循环 $T(n) = O(m \times n)$：

```c
for (col = 0; col < n; col++)
    for (row = 0; row < m; row++)
        n[col][row] = m[row][col];
```

三元组表转置要做三件事：① 行列维数互换（$m.rows \leftrightarrow m.cols$）；② 每个三元组的 $i$、$j$ 互换；③ 重排次序，使新表以 N 的行（即 M 的列）为主序。

**方法一：按需点菜（按 M 的列序转置）**

按 $n.a$ 的次序，依次在 $m.a$ 中扫描找第 `col` 列的三元组，找到就转置后放入。

- 时间复杂度 $T(n) = O(\text{M 的列数} \times \text{非零元个数}) = O(n \times t)$；
- 若 $t$ 与 $m \times n$ 同数量级，则 $T(n) = O(m \times n)$。

**方法二：按位就座（快速转置）**

先算出 M 每一列的非零元个数 `num[col]`，再求每列第一个非零元在 $n.a$ 中的位置 `cpot[col]`：

```
cpot[0] = 0;
cpot[col] = cpot[col-1] + num[col-1];     // 1 <= col < m.cols
```

然后按 $m.a$ 的顺序扫描一遍，把每个三元组直接放到 `cpot[列号]` 的位置，放完 `cpot[列号]++`。

- 时间复杂度 $T(n) = O(\text{列数} + \text{非零元个数}) = O(n + t)$；
- 若 $t$ 与 $m \times n$ 同数量级，仍为 $O(m \times n)$，但**系数小得多**；
- 代价：需要 `num`、`cpot` 两个长度等于列数的辅助数组，空间 $O(n)$。

课件例子的 `num` / `cpot` 表（$m.cols = 7$）：

| col | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| num[col] | 1 | 2 | 2 | 1 | 0 | 1 | 0 |
| cpot[col] | 0 | 1 | 3 | 5 | 6 | 6 | 7 |

**（4）链式存储**

- **带行指针向量的单链表**：每行一个单链表，另设行指针数组指向本行第一个非零元，某行无非零元则为空。存 $t$ 个非零元需 $3t + m$ 个存储单元（每结点存 col、val、next 三个域）。
- **十字链表**：设行、列指针数组，分别指向每行、每列的第一个非零元，结点存 `row, col, val, down, right` 五个域。

```c
typedef struct node {
    int row, col, val;
    struct node *down, *right;
} JD;
```

建立十字链表的思路（课件给了）：对每个非零元 $(r, c, v)$，在第 $r$ 行链表和第 $c$ 列链表中各找一个插入位置，分五种情况处理：本行为空、走到行末、同列已存在（改 val）、插在行首、插在行中。

## 四、易错点清单

1. 空串长度 0，空白串长度 1，子串必须连续。
2. 地址公式里 $l$ 是“每个元素占的存储单元数”，别忘了乘；下标起点 0 和 1 的公式不同。
3. 对称矩阵只存 $\frac{n(n+1)}{2}$ 个，三角矩阵再 +1 存常数，对角矩阵 $3n-2$ 个。
4. 快速转置的 `cpot` 是“该列第一个非零元在新表中的起始位置”，不是个数；`num` 才是个数。
5. BF 最坏 $O(n \times m)$，别顺口说成 $O(n+m)$（那是 KMP）。
6. 三元组表转置时，行列维数要互换，很多题只记得换 $i$、$j$。

## 五、本章定位

课件到十字链表为止，没有单独布置作业。考试重心在第二、三节的**计算题**：给一个 $m \times n$ 数组和元素大小，求某个元素的地址；给一个对称矩阵元素，求它的一维下标 $k$；给一个三元组表，手写快速转置后的结果表并写出 `num` / `cpot`。
