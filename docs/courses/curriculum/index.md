# 计算机科学与技术 · 专业课地图

把培养方案里「专业教育课程」这一块单独抽出来，按修读学期排成一张图：
每门课的学分、学时构成（理论 / 实验 / 上机 / 实践）、考核方式、起止周和必修选修身份。
通识课（高数、英语、政治、体育等）和素质拓展课不在这页里。

数据来源：学校下发的《课程信息表》（2025 级 · 计算机科学与技术 · 天平校区），全表 83 门课，其中专业教育课程 48 门。

## 一、先看结论

- 专业课共 **48 门 / 107 学分**：必修 35 门 82 学分，任选 13 门 25 学分。
- 考核方式：考试 13 门，考查 35 门——大半专业课是交作品 / 写报告的，但 3 学分以上的理论课（计算机学科基础、计算机程序设计基础、电子电路与数字逻辑、数据库原理、计算机网络、编译原理）全是考试。
- 学时结构：理论 808 学时、实验+上机 612 学时，实验与上机约占总学时的 43%（不含按周集中做的实践课）。实验占比最高的一批是 60%（Web 交互技术、J2EE 开发技术、数字图像处理、以及几乎所有专业任选课），各类「课程实践」和毕业设计则不计学时、按 1-17 周挂整个学期。
- 真正的分水岭在大二下：一学期 7 门专业课（组成原理、数据库、算法、J2EE、计算机数学基础 + 两门实践），是四年里专业课最密的一学期。

## 四、三条主干课链

培养方案里的课不是散着的，顺着这三条线看就知道每门课在为谁铺路。

**编程与软件线**：计算机程序设计基础（大一上）→ 面向对象技术 + 面向对象技术课程实践（大一下）→ C/C++ 程序设计、数据结构、数据结构课程实践（大二上）→ 算法设计与分析、J2EE 开发技术（大二下）→ 软件工程 + 软件工程课程实践（大三下）。

**系统与硬件线**：计算机学科基础（大一上）→ 电子电路与数字逻辑（大一下）→ 计算机组成原理 + 课程实践（大二下）→ 操作系统 B、微机原理与接口、编译原理、操作系统实践（大三上）。

**应用与前沿线**：Web 交互技术（大二上）→ 数据库原理（大二下）→ 计算机网络、数字图像处理、云计算、Web 高级框架开发、自然语言处理、移动互联网开发（大三上）→ 人工智能基础 B、大数据技术与应用 A、信息安全技术、软件测试与质量保证（大三下）→ 毕业设计（大四下）。

## 六、怎么用这张表

- **选课季**：先看当学期的「必修」块，那是绕不过去的；「任选」块按兴趣挑，注意 8 周结课的快课（Web 高级框架、自然语言处理、信息安全技术等）和大作业撞车。
- **考前预估工作量**：`考试` 的课要留复习周，`考查` 的课看起止周——1-8 周的课期中就结束，别按期末节奏排。
- **查资料**：本站已有的课程直接点课程名跳过去；表里没链接的，就是还没整理。
