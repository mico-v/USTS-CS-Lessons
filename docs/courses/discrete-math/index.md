# 离散数学复习资料

本目录依据学习通《离散数学计算机》课程的**出版社配套课件**（共 10 章 PPT）整理，覆盖前 7 章。教材为王庆先、顾小丰、王丽杰编著《离散数学》（人民邮电出版社），课件里的定义编号、记号、算法步骤都照它来，做题时符号不会对不上。

写法上刻意照顾「第一次学」：每个概念先讲它在说什么，再上形式化定义，然后跟一个小例子；定理后面写清什么时候用、怎么用、哪儿容易错。

## 复习路线

**只剩一天**

1. 先看[速查表](./cheat-sheet.md)，把公式和判别流程过一遍（幂集、主范式编码、五性质矩阵特征、握手定理、树的 m=n−1、欧拉公式）。
2. 第 4、5 章的关系性质判定与等价类划分是必考计算，各做两道手算题。
3. 第 7 章的哈夫曼、欧拉/哈密顿判定背结论 + 走一遍例题过程。

**有两天**

1. 第 1、2 章是工具：集合恒等式与等价演算是后面所有证明的基础，两小时过完第 1 章，三小时过第 2 章。
2. 第 3 章量词规则最容易写错，重点看 US/ES 的限制条件与符号化对照表。
3. 第 4、5 章连着看：关系性质 → 闭包 → 等价关系 → 偏序，一条线下来逻辑是通的。
4. 第 6、7 章是图论，晚上精力好时看，算法部分一定要动手在纸上追一遍表。

**有三天以上**

按章顺序精读，每章把「本章小结」的表抄一遍，再闭卷做「自测题」，做错回去看对应小节。最后用[速查表](./cheat-sheet.md)自测默写。

## 这本书的题型分布（按课件重点推断）

- **选择/填空**：命题符号化、公式类型判断、主析取范式编码、幂集元素个数、关系性质判断、度数序列能否成图、树的边数与结点数、欧拉/哈密顿图的判定。
- **计算题**：容斥计数、真值表与主范式、关系复合与闭包矩阵、等价类与商集、哈斯图找极值元、Dijkstra/Floyd 最短通路、哈夫曼树与 WPL、平面图的面数。
- **证明题**：集合恒等式（成员表法或定义法）、推理有效性（演绎法 + CP/反证）、关系性质证明、树的性质证明。
- **应用题**：命题/谓词符号化、关系数据库、拓扑排序、编码与前缀码、中国邮路。
